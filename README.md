基于STM32的牲畜低功耗定位终端
-技术栈：C语言 | STM32 | FreeRTOS | 北斗/GPS | LoRa | 嘉立创EDA | 低功耗开发

✨ 项目简介
本项目基于网络公开教学例程入门学习，实现野外牲畜低功耗定位终端。使用STM32主控，定时唤醒北斗模块获取位置，通过LoRa远距离无线把坐标上报到网关；支持电子围栏判断，越界触发报警。经过对硬件的分析理解后，重点对整机休眠逻辑、通信可靠性做优化，调试整机功耗，延长电池续航。

📌 核心功能
1. 北斗+GPS双模定位，串口读取NMEA语句，解析经纬度、时间、定位状态
2. FreeRTOS多任务调度：定位采集、LoRa发送、围栏检测、低功耗休眠
3. 电子围栏逻辑：预设区域，判断坐标是否超出范围，越界标记报警
4. LoRa无线通信，数据打包重传机制，应对野外信号差、丢包问题
5. STOP模式休眠+定时唤醒策略，降低静态功耗，适配电池供电场景

🛠 踩坑记录 & 解决方案
- 问题：休眠唤醒后北斗模块经常定位失败，需要长时间搜星
  解决：增加模块电源控制引脚，休眠时断电，唤醒后上电并预留冷启动搜星时间
- 问题：LoRa报文丢包严重，野外干扰大
  解决：增加简单帧头、校验和、应答重传机制，限制单次数据包长度
- 问题：整机功耗偏高，电池使用时间短
  解决：不用外设全部断电，配置STM32进入STOP低功耗模式，关闭不用时钟

- 开发平台：Keil MDK

- RTOS：FreeRTOS
